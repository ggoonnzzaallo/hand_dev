Stops the pipeline and exits uv run launch in the terminal (~few seconds).

Start with uv run launch from the CamControls_UI folder. Webcam tracking runs as soon as the pipeline starts.

  • Pipeline — simulation vs real hardware (restarts ~10s). Real modes enable motor torque.
  • MuJoCo 3D view — optional viewer windows only; left/both require a pipeline that includes the left simulation node.
  • Serial — USB port for servos; scan while in simulation mode.
