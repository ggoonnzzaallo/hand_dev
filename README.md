# hand_dev

Standalone repo for **CamControls UI** (webcam hand tracking + simulation / real hardware for the Pollen Amazing Hand).

## Run

```bash
cd CamControls_UI
uv run launch
```

See [CamControls_UI/README.md](CamControls_UI/README.md) for prerequisites and troubleshooting ([GONZALO_NOTES.md](CamControls_UI/GONZALO_NOTES.md)).

## Re-export from AmazingHand

If you still maintain `AmazingHand/Demo` and want to refresh this subfolder:

```bash
AmazingHand/Demo/scripts/export_hand_dev.sh
```
